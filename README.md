# SwipeLocal — iPhone 本地视频流 PWA

一个纯前端、无服务端、无第三方依赖的实验性 PWA。可将用户主动选择的相册视频变成类似短视频应用的上下滑动播放列表。**视频不会上传到服务器**。

## 最快部署方法（免费 GitHub Pages）

1. 在 GitHub 创建一个公开仓库，例如 `SwipeLocal`。
2. 上传本文件夹内的 **全部文件** 到仓库根目录（请勿只上传 ZIP）。
3. 进入仓库 Settings → Pages → Build and deployment → Deploy from a branch，选择 `main` 和 `/ (root)`，点击 Save。
4. 等待 Pages 构建完成，打开页面给出的 `https://你的用户名.github.io/SwipeLocal/` 地址。
5. 在 iPhone Safari 中打开该 HTTPS 地址 → 分享 → 添加到主屏幕 → 打开为 Web App → 添加。
6. 从主屏幕打开 SwipeLocal，点“从相册选择视频”，可以一次选择多个视频。向上滑下一个，向下滑上一个。

GitHub Pages 部署的网站代码是公开的，**但导入的视频仅在本机处理，不会被上传**。不需要 Apple Developer 付费账号。

## 功能

- 上下滑切换，切换后自动尝试播放，当前视频循环播放；左右区域任意位置轻点暂停/继续。
- 默认静音，以符合 Safari 的自动播放策略；可以手动点击声音按钮试着有声播放。切换时有声播放是否持续取决于系统策略。
- 竖屏满屏裁剪或等比完整显示切换。
- 可批量导入 iPhone 相册的视频。
- 可选“保存导入的视频”：IndexedDB 把视频复制到此应用的本地存储（可能占用与原文件相近的额外空间）。
- 已保存的视频可在下次打开时恢复；PWA 的代码由 Service Worker 缓存，已缓存的代码与已保存视频可离线使用。
- **保存当前帧（新增）**：播放时点击右侧 📸「截图」，立刻截取当前视频画面，打开截图预览。截图保留原视频帧的宽高（而非手机屏幕的裁切比例），不含播放器文字/按钮，以高品质 JPG 导出。预览中可选择「分享图片」或「下载图片」。
- **在 iPhone 照片中保存截图**：截图预览里**长按图片**，在系统菜单中选择「存储图像」/「存储到照片」（实际文字依 iOS 版本而异）。部分 iOS 版本的「分享图片」菜单不提供保存照片选项，因此长按预览图是更可靠的方式。网页不能直接无交互写入系统照片图库。
- 可从播放列表移除视频；如已有应用内副本则删除该副本，不会删除 iPhone 相册原视频。

## 已知限制

- 由于 iOS 沙盒和网页权限，无法自动枚举/读取整个照片图库。必须由用户在系统选择器中主动选择。
- 未保存到 IndexedDB 的视频仅在当前页面会话内可播放，重新打开一般需再次选择。
- 保存到 IndexedDB 会复制视频、消耗额外储存空间；可能遇到浏览器配额限制或系统清理，不能作为唯一备份。
- Safari 限制有声自动播放。默认静音可减少卡顿和播放失败，用户可以点声音按钮尝试启用。
- 某些视频编码/容器可能不兼容，即使扩展名是 AVI 等；建议使用 iPhone 拍摄的 MOV 或 H.264 MP4。
- 此版本是最小可用原型，未经真实 iPhone 上 Safari 全面验证；截图功能需要所选视频已解码出当前画面。部分编码格式无法在 Canvas 正常输出。
- 「下载图片」在 iPhone 上可能将图片保存在「文件」而不是「照片」中。要存入「照片」，优先长按截图预览图并使用系统提供的存储操作。

## 本地开发（Mac）

可以用 `python3 -m http.server 8080` 在本文件夹启动开发服务器，在 Mac 浏览器测试 `http://localhost:8080`。iPhone 访问需要 HTTPS 才能正常使用 Service Worker；推荐部署到 GitHub Pages 测试。

## 隐私说明

前端代码仅使用浏览器 File API、IndexedDB 和 Service Worker。没有网络上传接口、统计 SDK 或服务器账户。上传至 GitHub Pages 的只是 App 程序文件，不包含你后来选择的私人视频。
